PHAROS — AI agent workspace for cross-border sellers

HOW TO OPEN: double-click PHAROS_v1.0.html. No install, no internet, no login.
Everything is inside this one ~720 KB file. Chrome / Edge / Safari recommended.

WHAT IS INSIDE: the landing page explains the product; click "Open the workspace"
for 9 specialist agents, 6 operations modules, and a work hub that aggregates tasks
from 18 connected platforms (Feishu, DingTalk, WeCom, email, Amazon, TikTok Shop,
Temu, Payoneer, freight forwarders, test labs …) into a single inbox you can assign
to a person and turn into a tracked task.

MODEL ACCESS: top bar ⚙ → pick a provider → paste your own API key. 22 providers,
4 protocols. With no key it runs on a built-in simulation engine, so every screen
still works.

THIS COPY CONTAINS NO API KEYS and all data is fictional sample data.
Use the 🌐 button in the top bar to switch language.
