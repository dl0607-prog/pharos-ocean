# PHAROS 出海工作台 · 使用说明

> 面向中小出海商家的一站式系统:填一份资料,AI 给你能直接执行的出海方案;选平台、拿入驻指南、记进度;8 位出海智能体随叫随到。接入任意 OpenAI 兼容 API Key 即可使用。

## 一、三步上手

1. **打开系统** → 海面入口(金色海面,可以向下滚动「下潜」到底)→ 弹出注册/登录
2. **配置 AI**:右上角 ⚙「模型接入」→ 选服务商(DeepSeek / 智谱 / 通义 / Kimi / OpenAI / 硅基流动)→ 粘贴 API Key → 保存并测试连接,看到绿灯即完成
3. **开始使用**:左侧栏顶部「🚀 出海启动」→ 按向导填 4 步资料 → AI 生成你的专属出海方案

## 三、出海启动详细流程

1. **商家情况**:公司类型、营业执照、商标、出海经验、启动预算、团队规模
2. **产品信息**:主营品类、产品介绍、客单价、供应链、已有认证
3. **目标市场**:可多选(美国/欧洲/东南亚/中东/拉美/日韩/其他)+ 首选市场
4. **确认生成**:核对资料 → 点「⚡ 生成我的出海方案」(约 30-60 秒)

生成后可随时「✏️ 修改资料」「⚡ 重新生成」。方案不是教程,是直接能照着执行的开店计划。

## 四、AI 服务配置(接入 API 即可用)

支持**任意 OpenAI 兼容接口**,常用服务商预设:

| 服务商 | Base URL | 模型示例 |
| --- | --- | --- |
| DeepSeek | https://api.deepseek.com/v1 | deepseek-chat |
| 智谱 GLM | https://open.bigmodel.cn/api/paas/v4 | glm-4-flash |
| 通义千问 | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |
| Kimi | https://api.moonshot.cn/v1 | moonshot-v1-8k |
| OpenAI | https://api.openai.com/v1 | gpt-4o-mini |
| 硅基流动 | https://api.siliconflow.cn/v1 | deepseek-ai/DeepSeek-V3 |

- 配置保存在服务器 `data/settings.json`,立即生效、重启不丢
- 出于安全,接口地址仅允许公网 http/https(拒绝本机/私网地址)
- Key 仅保存在你自己的服务器上,前端不会外传

## 五、部署与运维

**本机运行:**
```bash
git clone https://github.com/dl0607-prog/pharos-ocean.git
cd pharos-ocean
bash start.sh          # http://localhost:8320
```

**腾讯云服务器部署**(在服务器网页终端里粘贴):
```bash
curl -fsSL https://raw.githubusercontent.com/dl0607-prog/pharos-ocean/main/deploy.sh -o /tmp/pharos.sh && bash /tmp/pharos.sh
```
- 自动装环境、下载代码、注册开机自启服务 `pharos`(内部 8320 端口,8088 对外)
- 完成后访问 `http://<公网IP>:8088`;打不开时在控制台「防火墙」放行 TCP 8088
- 数据备份:重复部署会自动备份/恢复 `data/` 目录
- 常用运维:`systemctl restart pharos`(重启)、`journalctl -u pharos -n 100`(看日志)

## 六、常见问题

**Q:智能体不回复 / 提示「尚未配置 AI 服务」?**
点右上角 ⚙ 填 API Key,或复制 `.env.example` 为 `.env` 填 `LLM_API_KEY` 后重启。

**Q:换一台电脑登录,数据还在吗?**
在。对话、出海方案、平台进度、团队成员全部存在服务器数据库,按账号隔离。

**Q:团队成员怎么加?**
左侧栏「👥 添加成员」,或直接在团队页管理(编辑/移除)。

**Q:三栏布局(左导航 / 中内容 / 右团队面板)如何收起右侧面板?**
右侧面板为常驻设计,不提供收起;需要更大中间空间时最大化浏览器窗口即可。
