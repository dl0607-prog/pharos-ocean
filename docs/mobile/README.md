## 与设计稿的已知差异

1. **启动页**使用公开授权的金色海景照片，而非设计稿中的灯塔礁石照片（未能获取到同款授权素材）。
2. **智能体命名**沿用产品现有 8 位智能体（出海参谋 / 出海体检 / 文化洞察 / 市场调研 / 文案创作 / 创意素材 / 合规审查 / 增长顾问），未改成设计稿中的「市场分析师 / 选品专家」等，以保证 PC 端与手机端、后端 Prompt 一致。
3. **示例数据**（市场规模 $1.2B/$856M/$620M、选品评分 85/78/76/72、$320B 市场卡）均在界面上标注「示例数据 · 仅示意」，真实结论由 AI 生成。
4. 设计稿中的 iOS 状态栏（9:41、信号、电池）为系统 UI，网页中不实现。

## 数据与同步

- 手机端与 PC 端共用同一 FastAPI 后端与账号体系（`/api/auth/*`）
- 出海计划（`/api/launch/plan`）、平台进度（`/api/launch/platforms`）、团队（`/api/team`）、对话（`/api/conversations`）全部服务端存储
- AI Key 仅保存在服务器，接口只返回脱敏值（`llm_key_masked`），不会下发到手机或任何客户端
